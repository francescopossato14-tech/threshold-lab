# Threshold Lab — formulário de interesse

Página estática (GitHub Pages) do formulário de validação do Threshold Lab, um treino de limiar em grupo separado por faixa de pace, em Florianópolis.

- `index.html` — o formulário. Configuração no topo do `<script>`: `ENDPOINT` (URL `/exec` do Apps Script) e `PONTOS`.
- `apps-script.gs` — código que roda na planilha Google e grava as respostas. Não é servido pela página; as instruções de instalação estão no topo do arquivo.
- `icone.svg` — favicon.

As respostas ficam numa planilha Google privada. Este repositório não guarda dado de ninguém.

Links com origem, para saber o que converte: `?o=bio`, `?o=post3`, `?o=whats`.
